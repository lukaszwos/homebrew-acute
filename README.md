# Lukaszwos Acute

## How do I install these formulae?

`brew install lukaszwos/acute/<formula>`

Or `brew tap lukaszwos/acute` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lukaszwos/acute"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
